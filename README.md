Employee Data Analysis

Project Overview
This project focuses on analyzing employee data to understand workforce distribution, salary trends, employee performance, experience, overtime, and attrition.

The project uses Python, MySQL, Microsoft Excel, and Power BI to perform data cleaning, data analysis, and interactive dashboard creation.

Project Objectives
- Analyze employee distribution across departments and locations.
- Calculate average salary and employee experience.
- Understand employee performance ratings.
- Analyze employee attrition.
- Examine overtime patterns.
- Create interactive dashboards to support data-driven decisions.

Dataset Description
The dataset contains 500 employee records and 14 columns.

Key columns include:
- EmployeeID
- EmployeeName
- Age
- Gender
- Department
- JobRole
- EducationLevel
- Location
- HireDate
- ExperienceYears
- SalaryINR
- PerformanceRating
- Overtime
- Attrition

Tools and Technologies
 Python:Data cleaning, preprocessing, and visualization.
 MySQL:Data storage and SQL analysis.
 Microsoft Excel:PivotTables, PivotCharts, slicers, and dashboard creation.
 Power BI: DAX measures, interactive visualizations, and dashboard creation.

Project Workflow

1. Python
- Loaded and explored employee data.
- Handled missing values.
- Cleaned text columns.
- Standardized department names.
- Converted date columns.
- Performed exploratory data analysis.
- Created visualizations.

2. MySQL
- Created database and employee table.
- Performed employee count analysis.
- Analyzed department-wise salary and employee distribution.
- Analyzed location-wise employee count.
- Examined attrition and overtime.
- Used aggregate functions, GROUP BY, subqueries, and window functions.

3. Microsoft Excel
- Imported cleaned employee data.
- Created 7 PivotTables and PivotCharts.
- Created KPI cards.
- Added interactive slicers.
- Built an employee analysis dashboard.

4. Power BI
- Imported and transformed employee data.
- Created DAX measures.
- Built KPI cards:
  - Total Employees
  - Average Salary
  - Average Experience
  - Attrition Rate
- Created interactive charts.
- Added slicers for Department, Location, Gender, and Job Role.

Key Analysis and Visualizations
- Employee Distribution by Department
- Average Salary by Department
- Employee Distribution by Location
- Employee Distribution by Experience
- Employee Performance Rating Distribution
- Employee Attrition Analysis
- Employee Overtime Analysis
